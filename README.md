## Lo que hago

Un ejemplo real: así responde mi asistente virtual cuando un negocio está cerrado.

1. **23:40 · Suena el teléfono.** Un cliente quiere reservar para mañana y no hay nadie para cogerlo.
2. **23:40 · Contesta la IA.** El asistente entiende lo que le piden, pregunta lo que falta y habla como una persona.
3. **23:41 · La reserva se apunta sola.** Comprueba si hay hueco y guarda la cita en la agenda, sin dobles reservas.
4. **23:41 · Llega el WhatsApp.** El cliente recibe la confirmación al momento y el dueño se encuentra el trabajo hecho por la mañana.
